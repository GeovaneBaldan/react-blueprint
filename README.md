# React Blueprint

**React Blueprint** is the next evolution in code generation for React ecosystems. Designed to be fast, extensible, and precise, this extension helps you maintain architectural consistency by generating components, hooks, and contexts in seconds.

## Features

React Blueprint provides a robust set of scaffolding tools to accelerate your development workflow:

- **Smart Scaffolding:** Create React (Web) and React Native components with pre-defined, clean structures.
- **Custom Hooks & Contexts:** Generate the boilerplate for Hooks and Context API without repetitive manual typing.
- **Folder-First Architecture:** Automatically organizes files (index, styles, tests) within standardized directory structures.
- **Extensible Design:** Built to adapt to your coding style, whether you use CSS-in-JS, Tailwind CSS, or Native StyleSheets.

## Requirements

- **VS Code v1.75.0** or higher.
- A project running React 16.8+ (for Hooks support) or React Native.
